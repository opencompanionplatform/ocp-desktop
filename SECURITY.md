# Security Policy (SEC-051)

## Reporting a vulnerability

Email: opencompanionplatform@gmail.com (official project security contact; migrate to a dedicated security@ project alias when a project domain is available).

- Please include: affected component, reproduction steps, impact assessment.
- We follow **90-day coordinated disclosure**: we acknowledge within 7 days, aim to fix within 90, and credit reporters unless they prefer otherwise.
- Do not open public issues for vulnerabilities.

## Scope

The OCP kernel, event bus, plugin host/SDK, memory layer, AI router, runtime IPC, and marketplace signing (ADR-0011). Binding requirements: ocp-architecture/08-guidelines/SECURITY_STANDARD.md (SEC-001..051); threat model: ocp-architecture/13-quality/THREAT_MODEL.md (X1–X7).

## สรุปภาษาไทย

นโยบายรายงานช่องโหว่ตาม SEC-051: แจ้งทางอีเมล opencompanionplatform@gmail.com (อีเมล Security Contact อย่างเป็นทางการของโครงการ; ภายหลังย้ายเป็น security@ ของโดเมนโครงการเมื่อพร้อม) ห้ามเปิด public issue, ใช้ coordinated disclosure 90 วัน ตอบรับใน 7 วัน — ขอบเขตครอบคลุม kernel, plugin host, memory, router, IPC และระบบ signing
